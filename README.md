# Rash Studio

**Ideas in motion. Built for the open web.**

[Open the studio](https://ruvnet.github.io/Rash/) · [MCP setup](https://ruvnet.github.io/Rash/mcp/connect.html) · [User guide](docs/user-guide.md) · [Compatibility](docs/compatibility.md) · [Flash parity plan](docs/flash-parity.md) · [Architecture](docs/adr/001-svg-scene-and-worker-runtime.md) · [Security](docs/security.md)

Rash is an open source SVG animation studio with a Rust/WebAssembly scripting runtime, a visual timeline, and portable JavaScript embeds. It brings the stage, layers, tools, properties and frame based workflow of classic Flash into a responsive browser editor.

The twenty second header tours design, motion, 3D and publishing. It is a bespoke, script free SVG using Rash’s production geometry projection, with a static reduced motion fallback. It is not an editor project; the six studies below include editable source and unmodified system exports. Reproduce it with `npm run header:generate`, then verify with `npm run test:header`.

**Status: experimental v0.6.0.** Native Rash scripting implements a documented ActionScript inspired subset. It is **not complete ActionScript or Flash API compatibility**. Existing SWFs use a separate, optional Ruffle Rust/WASM compatibility player, with upstream compatibility limits. Source `.as` is not compiled to SWF. See the [compatibility matrix](docs/compatibility.md) and [UI acceptance audit](docs/ui-acceptance.md).

```sh
npx @ruv/rash
```

This starts the complete Studio on `http://127.0.0.1:4173`. Use `npx @ruv/rash mcp` for the local MCP server, or install globally to use the `rash` and `rash-mcp` commands.

Create, list, edit, render, export and delete validated animations through seven MCP tools. Local Claude projects use private files; the hosted adapter uses authenticated R2 storage. These are separate stores, with JSON export for portability.

The [authenticated Studio](https://rash-svg-studio.ruv.chatgpt.site/studio/) now opens and saves the same hosted MCP projects. Choose **MCP → Manage cloud projects** to browse, open, save a revision, create a copy or delete with confirmation. Device autosave stays local; cloud saves are explicit. ### Open an example in the editor

1. Open the [gallery](https://ruvnet.github.io/Rash/examples/) and download **Project JSON** below an example.
2. Open [Rash Studio](https://ruvnet.github.io/Rash/) and choose **File → Open project**. On a phone, use **More → Open project**.
3. Change a layer, curve, camera pose or mask, then export your own version.

All six animated SVGs total **912.3 KB** uncompressed, or **104.9 KB** summed gzip. These are measured file sizes, not a guarantee of CDN transfer encoding. More geometric detail and more sampled frames increase 3D SVG size. The gallery uses the compact projects with the live retained player instead.

The advanced studies combine existing motion design tools. They do not add textures, a shared 3D depth buffer, AEP import or full After Effects compatibility. The [manifest](web/examples/manifest.json) records exact sizes, export hashes and generator source hashes.

Regenerate every SVG, project, poster and manifest with:

```sh
npm run examples:generate
npm run test:examples
```

### Reusable symbols and nested timelines

Convert a selected layer with **Properties → Convert to symbol**, give it a name, then open **Library** to place more instances. **Edit symbol** opens its own stage and timeline. A shared definition edit updates every instance. Convert a layer inside that definition to nest another symbol; the breadcrumb returns to its parent or Scene.

Each instance supports **Loop**, **Play once** and **Single frame**, with first frame and parent start offsets. Definitions have their own dimensions, camera and duration, and share the document FPS. Save, Undo, autosave, SVG export and embeds preserve the whole project while a definition is open. On phones, **More → Convert to symbol**, the inspector and Library expose the same operations. Delete an instance with the visible selection toolbar; a definition can be deleted after its references are removed.

These are deterministic graphic symbols. Independent MovieClip clocks, button states and frame scripts remain on the [Flash parity plan](docs/flash-parity.md). Symbol documents use schema version 2; older players reject them. Instance blur and glow are unavailable; apply those effects to artwork inside the definition. [Symbol architecture](docs/adr/009-symbols-and-nested-timelines.md) · [Release verification](docs/release-0.5.0.md).

### 3D and motion design

Open **3D** to add a box, sphere, torus or pyramid. Use **Scene camera** to adjust perspective and orbit. Choose a frame and **Set camera keyframe** to save a pose; move to another frame and save another pose. Camera keys appear in the timeline and can be removed from the camera dialog. The inspector exposes X/Y rotation, depth, wireframe, blur, glow and blending. In **Motion**, apply Fade, Rise, Pop, 3D revolution, Float or Focus reveal, then edit the generated keys and easing curves. Choose **Motion property** to give opacity, position, rotation or effects their own easing at a shared keyframe. **All properties** explicitly resets those overrides. Existing timing is retained when a preset shares a keyframe with another property.

Start with the **Beyond / 3D motion** template for an animated composition. On phones, **More → 3D objects and camera** provides the same controls. Three.js geometry is projected into SVG; editor, embeds and exports share that renderer. The pinned Three.js module adds 25.3 KB gzip.

These are motion design tools inspired by After Effects, with no AEP import, expressions, feathered masks or shared depth buffer between objects. Animated 3D SVG samples geometry and can be large: the eight second Beyond template exports approximately 3.45 MB. Limits are 32 mesh layers, 4,096 source triangles and 16 MB per SVG export. [Design and limits](docs/adr/006-three-svg-motion.md) · [Camera and timing design](docs/adr/007-camera-and-property-timing.md) · [Release verification](docs/release-0.4.0.md).

### Reveal masks

Select any text, vector or 3D layer and open **Properties → Reveal mask**. Choose Rectangle or Ellipse, then edit local position, dimensions and rotation. Numeric mask values animate at the current frame. **Animate mask** opens Wipe reveal; Iris reveal is also available. The **Mask reveal** template demonstrates both effects. Set independent mask easing in **Motion**.

**Fit mask to layer** resets the mask to the evaluated layer bounds at the current frame. **Remove mask**, or choosing None, clears mask tracks in one undoable edit and preserves other animation. A zero size mask hides content completely; select that layer from **Layers** to edit it again. Masks use hard clipping with no feathering, inversion or layer references. Stage, embeds, PNG and animated SVG share the evaluated geometry. Older players ignore masks and show unclipped content.

### Edit on a phone

1. Tap an object on the canvas, or choose it from **Layers**.
2. Use the visible **Edit**, **Duplicate**, or **Delete** actions above the canvas. Corner handles resize shapes; the inspector provides exact sizes and rotation.
3. For text, choose **Edit**, then **Edit text content**. Multiline text is preserved in the SVG and exports.
4. Use **Undo** and **Redo** above the canvas. **More** exposes saving, importing, exports, scripts, resources, and help without a keyboard.
5. In **Motion**, enter an exact frame to add, edit, or remove a keyframe. Changing FPS preserves keyframe timing in seconds, subject to frame rounding.

The browser keeps one current composition. Download project JSON before replacing it. Creating a new composition asks you to confirm replacement when there is existing work. The Orbit Collector demo supports touch and keyboard controls in the editor and JavaScript embed. Playback uses temporary game state and leaves the authored scene intact. This demo is not a general game engine.

cd Rash
npm ci --ignore-scripts

```actionscript
var total:Number = 0;
for (var i:int = 0; i < 10; i++) {
  total += i;
}
trace(total);
stop();
```

Use `getNode("layer-id").x = 120;` to modify a scene object. Execution has instruction, source, memory, recursion and output budgets. A failed run discards its commands. Scripts cannot access the DOM, browser storage, network, or operating system. This is a purpose built interpreter, never JavaScript `eval`.

## Architecture and governance

The [ADRs](docs/adr/) document scene ownership, rendering, worker isolation, local resource addresses, search, evaluation and packaging. [MetaHarness](scripts/metaharness-evaluate.mjs) records a static repository score and measured search checks. It does not certify quality or demonstrate self improvement.

Ruflo AI Team records task ownership; concurrent Codex workers implement isolated modules. ruOS provides deployment and independent execution evidence. Federation was unavailable during the initial build, so no federation execution or successful claims are asserted.

The product target is a complete Flash authoring and runtime replacement. The [delivery plan](docs/flash-parity.md) defines eight milestones with executable acceptance gates. FLA import, full AS1/AS2/AS3 semantics and Flash APIs, independent MovieClips, Stage3D, synchronized audio/video, collaborative storage and a general game engine remain unfinished. SVG rendering alone does not establish compatibility.
