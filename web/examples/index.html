Make it yours

  1. Download a project JSON file below an example.
  2. Open Rash Studio and choose File → Open project. On a phone, use More → Open project.
  3. Edit a layer or keyframe, then export your version as SVG, GIF, PNG, HTML, PDF or a supported MP4.

SVG previews loop independently when opened as images. These players start paused and provide playback controls. Static posters are available for every study. Three.js geometry is projected into SVG; objects follow layer order, with no shared depth buffer or textures.

Created with Rash 0.4.0. All preview elements are editable scene layers. No external image assets, fonts or animation services.
