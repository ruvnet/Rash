One idea. An open canvas.

Draw it, give it character, add another dimension, then take it to the web. This twenty second SVG explains the tools already available in Rash. Nothing is rendered as a video, and the SVG makes no external requests.

  1. Design

    Editable vectors, text, layers, history, local autosave and templates. Web, social and print sizes. Touch editing on phones and a complete desktop workspace.

  2. Choreograph

    Keyframes, independent Bezier curves, motion presets and stagger. Rectangle and ellipse reveal masks, blur, glow and blend modes.

  3. Direct in 3D

    Three.js box, sphere, torus and pyramid geometry projected into SVG. Animate object depth, rotations and a shared perspective camera.

  4. Publish

    Animated SVG, GIF, PNG, HTML, project JSON and raster PDF stills. MP4 in supporting browsers. Responsive JavaScript embeds with their own controls.

Under the stage: bounded Rust/WASM scripting in a Web Worker, RuVector template search, local rash:// resources, Claude authoring and verification skills, MetaHarness evidence tooling, a collector game demo, and optional isolated Ruffle playback for existing SWFs.
