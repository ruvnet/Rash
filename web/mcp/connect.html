Local Claude plugin

Requires Node.js 22 or newer and Git. In Claude Code:

/plugin marketplace add ruvnet/Rash
/plugin install rash@rash-tools

For a standalone stdio server:

git clone https://github.com/ruvnet/Rash.git
cd Rash
npm run mcp

Configure your MCP client to run node /absolute/path/Rash/mcp/server.mjs. The default store is ~/.rash/projects; override it with RASH_MCP_STORE.

Seven tools. One scene format.

ToolWhat it does
rash_project_createCreate a validated scene from a template or complete project.
rash_project_listList your saved animations and revisions.
rash_project_getRead a project before editing it.
rash_project_updateSave changes using the expected revision; stale edits are rejected.
rash_project_deletePermanently delete a project after checking its revision.
rash_renderRender a specified frame from an exact saved revision.
rash_exportExport JSON, still SVG, animated SVG or an HTML embed.

From conversation to composition

  1. Create an animation from Orbital motion, 3D dimension or a blank scene.
  2. Play and seek frames. Edit its name, layer position or fill, then save.
  3. Download project JSON to continue in the full studio, including shared symbols, camera tracks, masks and motion curves.
  4. Export portable SVG or an embed. Use the full studio for browser dependent GIF, MP4, PNG and PDF output.

Browser autosave, local MCP storage and hosted MCP storage are separate. Transfer projects explicitly with JSON. Deleting an MCP project is permanent; download a backup first.

Verified, with clear boundaries

145 unit tests and nine MCP interface checks in each of Chromium and WebKit passed for v0.6. All seven hosted tools were also exercised through a connected ChatGPT plugin. Browser tests cover mobile edits, deletion, exports, conflicts and host result handling.

Native host visual acceptance and live Claude acceptance remain separate checks. Full Flash and ActionScript compatibility is still in development.
